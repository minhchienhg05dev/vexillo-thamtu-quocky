# Thám tử quốc kỳ (Vexillo)

Trò chơi đoán luật kết hợp có Lift cao nhất, tính bằng Apriori trên 194 quốc kỳ của bộ dữ liệu UCI Flags (1990).

- Nhóm 7, học phần Khai phá dữ liệu, Trường Đại học Giao thông Vận tải
- Ngưỡng: MinSup 10%, MinConf 60%, Lift > 1 (giống notebook Vexillo)
- Dữ liệu: UCI Machine Learning Repository, Flags, DOI 10.24432/C52C7Z (CC BY 4.0)

Toàn bộ trang nằm trong `index.html`, không cần cài đặt hay build.
